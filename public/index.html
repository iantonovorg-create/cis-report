⚙️ Подключение к Google Sheets

1.Открой свою Google таблицу, скопируй ID из адресной строки:
docs.google.com/spreadsheets/d/[ЭТО_И_ЕСТЬ_ID]/edit
2.Сделай таблицу публичной: Файл → Настройки доступа → «Все, у кого есть ссылка» → Читатель
3.Вставь ID выше и нажми «Подключить»
4.Структура листов описана в инструкции ниже ↓
